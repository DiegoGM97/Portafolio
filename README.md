# Portafolio Personal (Astro)

Portafolio listo para usar. Solo necesitas editar tus datos en un archivo.

## Donde editar tu informacion

Abre [src/pages/index.astro](src/pages/index.astro) y cambia estos bloques:

- `profile`: nombre, rol, ubicacion, descripcion, correo, telefono y links
- `skills`: lista de habilidades
- `experience`: experiencia laboral
- `projects`: proyectos destacados

No necesitas tocar el HTML si no quieres; con cambiar esos datos ya queda personalizado.

## Comandos

Ejecuta desde la raiz del proyecto:

```bash
npm install
npm run dev
```

Luego abre `http://localhost:4321`.

## Build de produccion

```bash
npm run build
npm run preview
```
